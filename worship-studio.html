Worship Studio Home Control → Display ↗

Connect once, then never again

This page saves lyric edits straight into the song library. To do that it needs permission to write to the church's website. That's a one-time setup on this computer — about two minutes.

  1. Open this GitHub page ↗ (sign in if it asks).
  2. Give it a name — anything, like worship studio.
  3. Under Expiration, pick No expiration so you don't have to redo this.
  4. Under Repository access, choose Only select repositories and pick legacy-bible-church.
  5. Under Permissions → Repository permissions, set these two to Read and write:
    Contents  and  Actions
  6. Click Generate token, copy it, and paste it below.

The token is stored only in this browser, on this computer. It is never put on the website and nobody else can see it. It can only touch this one repository — you can delete it any time from GitHub's settings page.
