Get Sunday ready — any time before Sunday

1
Put in this week's songs
Open the planner. In column A, delete last week's songs and type this week's — one per row. Leave B, C, D blank for now.
Open the planner →
2
Wait about 20 minutes
The system searches YouTube, picks likely videos, and drafts the lyrics for each song. Nothing to do here — just give it time.
3
Review and approve each song
Open the prep page. For each song:
• If it says “no review needed” — just set that song's column C to Approve in the planner.
• Otherwise — tap the video that sounds right, read the lyrics under it, then copy its link into column B and set column C to Approve.
• Wrong words? Type the fix in column D, e.g. verse 2 line 3 is “grace” not “grace's”.
Open the prep page →
4
Check it's done
Wait ~20 more minutes, then re-open the prep page. Every song should show Approved, and it shows up in the This Sunday box at the top of this page. That's it.

Sunday morning

Open Control on the laptop

Open Control →
2
Open Display and move it to the TV
Open it in a second window, drag that window onto the TV, make it full screen. It follows Control automatically.
Open Display →
3
Open Song Videos for the audio
Each song has a red Play button that opens the right YouTube video. Start the video here, run the words from Control.
Open Song Videos →
4
Run the service
On the laptop: ← → change slides, B blanks the screen, tap any slide to jump to it. On a phone: use the big Prev / Next buttons.
